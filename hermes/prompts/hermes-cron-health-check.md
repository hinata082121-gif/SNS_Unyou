# Hermes cronヘルスチェックプロンプト

## 出力

`docs/reports/infra/health-checks/YYYY-MM-DD-hermes-cron-health-check.md`

## 確認

- Gateway状態
- cron status
- active jobs
- next_run
- last_run_at
- last_status
- missed run
- daily-sales-candidates作成状況
- 9:00タスク
- 月水リサーチ
- 金曜市場分析
- 補完チェックタスクがある場合はその状態
- エラーログ
- 対応案

## ルール

タスク登録/削除は行わない。状態整理と人間が確認すべきことの提示までに留める。
