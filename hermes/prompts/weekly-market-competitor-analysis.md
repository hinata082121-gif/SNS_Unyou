# 週次市場・競合分析プロンプト

## 目的

毎週1回、ICHI Socialの市場分析・競合分析・営業改善・サービス改善レポートを作成する。

## 実行頻度

- 毎週金曜 17:00

## 対象サービス

- ICHI Social
- 小規模店舗向けSNS運用代行
- Instagram運用代行
- 美容室向けSNS支援
- ネイル/アイラッシュサロン向けSNS支援
- 整体院向けSNS支援
- カフェ/飲食店向けSNS支援
- 地域密着型Web/SNS集客支援
- フリーランスSNS運用代行

## 対象地域

- 川口市
- 蕨市
- 戸田市
- さいたま市南区
- さいたま市浦和区
- 東京都北区
- 東京都板橋区
- 必要に応じて足立区、荒川区、練馬区、豊島区、さいたま市中央区

## 調査内容

### 1. 市場動向

- 小規模店舗向けSNS運用代行の訴求傾向
- Instagram運用支援の一般的な提供内容
- 無料診断、無料相談、初回割引などの入口施策
- 業態別に刺さりやすい訴求

### 2. 競合分析

- 競合名
- URL
- 対象顧客
- 料金
- 初期費用
- 月額費用
- 提供内容
- 強い訴求
- CTA
- 無料診断の有無
- 実績の見せ方
- ICHI Socialとの差別化余地

### 3. 営業改善

- 反応が見込める業態
- 除外が多い候補の特徴
- 個人店・小規模店舗を見つけやすい検索キーワード
- チェーン/FC/総合SNSを避ける判断基準
- DM文面改善案
- メール件名改善案
- フォロー文面改善案

### 4. サービス改善

- ICHI Socialのプラン改善案
- 無料簡易SNS診断の改善案
- LP改善案
- Instagramプロフィール改善案
- Instagram投稿テーマ案
- 初回提案資料に入れるべき項目
- 月次レポート見本の改善案

### 5. 翌週アクション

- 重点地域
- 重点業態
- リサーチキーワード
- 営業文面の改善ポイント
- リスト更新ルールの改善点
- サービス改善タスク

## 出力形式

- Markdown
- 保存先:

```text
docs/reports/marketing/YYYY-MM-DD-weekly-market-analysis.md
```

## 必須ルール

- 営業メール送信は行わない
- SNS DM送信は行わない
- 問い合わせフォーム送信は行わない
- Googleスプレッドシートの自動更新は行わない
- `SECRET_TOKEN`、Webhook URL、APIキー、認証情報は表示しない
- 競合情報は公開情報のみを使う
- 出典URLを必ず残す
- 不確実な情報は `未確認` と書く
- 料金が不明な場合は推測せず `不明` と書く
- 架空実績や成果保証表現は作らない
- 競合を誹謗中傷しない
- 医療/整体領域では治療効果を断定しない
- 飲食店では予約導線を営業連絡に使えるか注意する
- 美容系では集客保証・効果保証表現を避ける
