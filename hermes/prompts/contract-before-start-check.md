# 着手前チェック用プロンプト

## 目的

受注後、ICHI Socialが実際に作業開始してよいかを確認する。

## 出力

保存先:

`docs/reports/admin/checklists/YYYY-MM-DD-store-name-before-start-check.md`

## チェック項目

- 申込書
- 契約条件
- 支払い
- 初期費用
- 対象SNS
- 権限
- 素材
- 確認者
- 投稿本数
- NG表現
- 成果保証しない旨
- 月次レポート希望
- キックオフ日程

## ルール

- 未確認項目がある場合は「着手保留」として理由を書く
- 支払い条件が未確認の場合は人間確認を必須にする
- SNS権限はパスワード共有ではなく正式な権限付与を優先する
- 実在の個人情報、口座情報、認証情報は出力しない
- SECRET_TOKEN、Webhook URL、APIキー、パスワードは表示しない

## 出力構成

1. 着手可否
2. 確認済み項目
3. 未確認項目
4. 着手前に人間が行うこと
5. 納品・制作部門へ渡す情報
