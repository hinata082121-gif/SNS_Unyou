# Gmail週次営業メール改善・反応率分析 2026-06-04

## 目的

毎週金曜17:00の市場・競合分析結果と、直近1週間のGmail営業結果を接続し、翌週の営業メールの件名、本文、CTA、訴求軸を継続改善する。

初期運用では改善案の作成までを自動化対象とし、本番テンプレートへの反映は人間承認後に限定する。

## 市場・競合分析との接続

金曜17:00の市場・競合分析では、SNS運用代行、小規模店舗支援、AI自動化、Gmail営業、Instagram集客の変化を確認する。

金曜18:00の営業メール改善タスクでは、その分析結果を営業メールへ落とし込み、翌週に試すべき件名・本文・CTA・訴求軸の改善案を作成する。

## 金曜18:00タスクの役割

- 直近7日間のGmail営業結果を安全に集計する
- 市場・競合分析の要点を営業メール改善へ変換する
- 翌週用の件名A/B案を作る
- 翌週用の本文A/B案を作る
- 業種別の訴求改善案を作る
- CTAと無料SNS診断導線を改善する
- 有料ミニ改善パックへの自然な接続案を作る
- Agent Office向けに安全な要約を記録する

## 入力データ

- 直近7日間の送信数
- 返信数
- 有望返信数
- 断り返信数
- 配信停止数
- 業種別反応
- 件名別反応
- 本文テンプレート別反応
- 金曜17:00の市場・競合分析結果

## 出力データ

- 翌週用の件名A/B案
- 翌週用の本文A/B案
- 業種別の訴求改善案
- CTA改善案
- 無料診断への導線改善案
- 有料ミニ改善パックへの接続案
- Agent Office用の安全な要約

## 禁止事項

- Gmail本番送信を行わない
- 自動返信を行わない
- 本番テンプレートを自動差し替えしない
- メールアドレスを表示・保存しない
- 営業先名を表示・保存しない
- 返信本文を表示・保存しない
- Gmailスレッド全文を表示・保存しない
- 秘密情報を表示・保存しない
- `data/gmail/` 本体、`data/prospects/`、`docs/reports/sales/`、`tmp/` をGit追加しない

## 初期運用ルール

- 改善案は `needs_review` としてAgent Officeに表示する
- 人間承認後のみ翌週テンプレートへ反映する
- 本番テンプレート差し替えは手動または別タスクで扱う
- 2〜4週間運用して安定したら、一部テンプレート差し替えの自動化を検討する

## Agent Office表示

表示するもの:

- 改善案作成済みか
- 承認待ちか
- 適用済みか
- blocked理由
- 直近7日間の安全な集計値
- nextAction

表示しないもの:

- メールアドレス
- 営業先名
- 返信本文
- Gmailスレッド全文
- 送信ログ本体
- 秘密情報
