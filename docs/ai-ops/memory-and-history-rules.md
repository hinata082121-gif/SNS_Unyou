# 記憶・履歴の扱いルール

## 固定情報

- サービス名: ICHI Social
- 小規模店舗向けSNS運用パートナー
- 外部送信や請求送付は自動化しない

## 変更される可能性がある情報

- 価格
- プラン内容
- 対象地域
- Hermesスケジュール
- モデル/ツール
- LP文言

## 最新確認が必要な情報

価格、プラン、スケジュール、環境変数、Webhook、Vercel設定、外部サービス仕様。

## 注意

- Hermes memoryに頼りすぎない
- ナレッジ索引を優先する
- 古い会話履歴を鵜呑みにしない
- Git commit履歴は参考にするが、最新ファイルを確認する
