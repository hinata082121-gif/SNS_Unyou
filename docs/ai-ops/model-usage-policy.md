# モデル利用方針

## Hermes Agent

- 向いている作業: 定期レポート、候補整理、レビュー、索引作成
- 向いていない作業: 外部送信、契約判断、支払い判断、秘密情報処理
- 注意: quota/credit、cron失敗、古い前提の利用

## Codex

- 向いている作業: リポジトリ内ファイル作成、コード/ドキュメント編集、lint/build確認
- 向いていない作業: 外部アカウント操作、Secrets変更、法務/税務判断
- 注意: 未追跡実運用ファイルを勝手にコミットしない

## ChatGPT

- 向いている作業: 企画、プロンプト設計、方針整理、アイデア出し
- 向いていない作業: リポジトリ直接編集、実設定変更

## 将来的な代替モデル

導入前に、出力品質、コスト、秘密情報リスク、禁止事項遵守、既存プロンプトとの相性を確認する。

## モデル切替時のチェック

- 同じテストケースで出力比較する
- 禁止事項を守るか確認する
- 保存先と出力形式が崩れないか確認する
- 人間確認事項が明記されるか確認する
- 自動でモデル変更しない
