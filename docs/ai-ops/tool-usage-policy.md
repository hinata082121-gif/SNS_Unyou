# AIツール利用方針

## 使ってよい

- ファイル読み取り
- docs作成
- レポート作成
- lint/build/check系
- Web検索
- 既存レポート参照
- git diff/status確認

## 人間許可が必要

- git commit
- git push
- スプレッドシート投入
- Hermesタスク登録/削除
- 設定ファイル変更
- .env関連確認

## 禁止

- 営業送信
- SNS DM送信
- 問い合わせフォーム送信
- SNS投稿
- 請求書送付
- 入金確認
- 契約判断
- 価格変更
- 秘密情報表示
- APIキー保存
- 未追跡ファイル削除
- 実運用レポートの勝手なコミット
