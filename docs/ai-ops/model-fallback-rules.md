# モデル/ツール フォールバックルール

## 想定

- Gemini quota exhausted
- モデルcredit不足
- Hermesモデル応答失敗
- Codex作業途中停止
- Web検索失敗
- tool timeout
- buildが通らない
- 大量ファイル編集で混乱
- 出力品質が落ちる

## まず確認すること

- エラーログ
- 実行したコマンド
- 入力プロンプト
- 出力途中の保存状態
- 秘密情報が含まれていないか

## 切り替え候補

- 時間を置いて再実行
- タスクを小さく分割
- Web検索なしでローカル情報だけにする
- HermesからCodexへ切り替える
- ChatGPTで方針整理しCodexで実装する
- 人間作業へ戻す

## 切り替え前の注意

- 秘密情報を再入力しない
- 古い出力を鵜呑みにしない
- 未完了ファイルを確認する
- 自動送信/設定変更はしない

## 切り替え後の品質確認

- 出力形式
- 禁止事項
- 保存先
- lint/build
- 人間確認事項
