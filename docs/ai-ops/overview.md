# AI運用改善部門 概要

## 目的

Hermes Agent / Codex / ChatGPT / 将来的な他モデルを、安定・安全・高品質・低コストに使い続けるための運用改善部門です。

品質管理・AI運用監査部門は「AI生成物を送信/公開前にチェックする部門」です。AI運用改善部門は「AIそのものの使い方、プロンプト、モデル、評価、改善サイクルを良くする部門」です。

## 管理対象

- Hermes Agent
- Codex
- ChatGPT
- 将来的な他モデル
- プロンプト改善
- モデル選定
- 出力評価
- 失敗分析
- コスト/クォータ管理
- コンテキスト管理
- 人間承認

## 他部門との接続

- 品質管理部門: 出力レビュー結果をプロンプト改善へ戻す
- ナレッジ管理部門: 最新の索引と運用ルールを参照する
- インフラ管理部門: Hermes、quota、ログ、実行失敗を確認する
- 全体統括部門: AI改善の優先順位とリスクを判断する

## Hermesに任せること

- プロンプトレビュー
- 回帰テスト
- AI出力評価
- 失敗分析
- モデル選定レビュー
- コスト/クォータ整理
- コンテキスト品質レビュー

## 人間が判断すること

- モデル変更
- 本番プロンプトの大幅変更
- Hermesタスク登録/削除
- 価格変更、契約判断、採用判断、支払い判断
- 外部送信、SNS投稿、請求送付
- 秘密情報ローテーション

## 自動化しないこと

モデルの自動変更、本番プロンプトの自動大幅変更、Hermesタスクの自動登録/削除、外部送信、SNS投稿、請求送付、契約判断、価格変更、採用判断、支払い判断、法務/税務判断、秘密情報表示、APIキー保存、.env変更、GitHub Secrets変更、Vercel環境変数変更は行いません。
