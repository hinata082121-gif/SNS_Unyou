# AI/ツール ルーティングルール

| 作業 | 推奨 | 理由 | 注意 |
|---|---|---|---|
| 企画/プロンプト設計 | ChatGPT | 発散と整理が得意 | 実装はしない |
| リポジトリ内ファイル作成 | Codex | ファイル編集と検証ができる | 未追跡実運用ファイル注意 |
| 定期レポート | Hermes Agent | cron運用に向く | 外部送信禁止 |
| 大量の定型下書き | Hermes Agent | 反復作業に向く | 人間確認 |
| UI/LP変更 | Codex | Next.js編集/検証ができる | 人間確認 |
| 外部送信 | 手動 | 誤送信防止 | AIに送信させない |
| 最終判断 | 人間 | 責任判断 | AIは補助 |
| 契約/税務/法務判断 | 人間/専門家 | 専門判断 | AIはたたき台のみ |
| 将来的な外注 | 人間管理 | 品質/秘密保持が必要 | AIはブリーフ作成まで |
