# プロンプト評価フレームワーク

| 評価項目 | A | B | C |
|---|---|---|---|
| 指示遵守 | 指示をほぼ満たす | 軽微な漏れ | 重要指示を外す |
| 出力形式 | 指定形式通り | 一部崩れ | 使いづらい |
| 正確性 | 事実/推測が分離 | 一部曖昧 | 断定や誤りが多い |
| 具体性 | 実務で使える | 追加修正が必要 | 抽象的 |
| 安全性 | 禁止事項を守る | 軽微な注意 | 禁止事項違反 |
| 秘密情報保護 | 値を出さない | 注意喚起不足 | 実値表示リスク |
| 自動化境界遵守 | 明確 | 一部曖昧 | 外部操作を促す |
| 実務利用可能性 | そのまま下書き利用可 | 加筆が必要 | 使いづらい |
| 人間確認事項 | 明確 | 一部不足 | 不明確 |
| 再現性 | 安定 | 条件次第 | ブレが大きい |
| コスト効率 | 適切 | やや冗長 | 過剰 |
| レポート保存 | 適切 | 命名調整が必要 | 保存先不明 |

総合評価はA/B/Cで記録し、Cの場合は改善案またはプロンプト修正を行う。
