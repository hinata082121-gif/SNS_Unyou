# 支払いルール

## 基本方針

- 月額費用は前払いを基本にする
- 初月は初期設計費と初月月額の支払い確認後に本格着手する
- 最終判断は人間が行う

## 支払いタイミング

- 初期設計費: 申込後、初期設計着手前
- 月額費用: 対象月の開始前
- オプション費: 発生前または発生月内

## 支払期限

- 原則、請求書発行日から7〜14日以内
- 個別条件がある場合は申込書/契約書に記載

## 振込手数料

振込手数料は原則クライアント負担とする。

## 支払い遅延時の対応

1. 丁寧な確認連絡
2. 支払い予定日の確認
3. 未払いが続く場合は作業停止
4. 契約条件に基づき終了判断

## 領収書/請求書

- 請求書はPDFまたはMarkdown下書きから作成
- 領収書が必要な場合は個別対応

## 消費税

税込/税別の表示を明確にする。インボイス対応は登録状況に応じて人間が確認する。

## キャンペーン適用時

- 初期3社限定の初期設計費無料キャンペーンは適用条件を明記
- 値引き額を請求書に明細として記載
