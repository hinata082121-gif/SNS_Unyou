# SNSアカウント権限ルール

## 基本方針

- パスワード共有を避ける
- Meta Business Suite等の正式な権限付与を優先する
- ログイン情報を平文保存しない
- 二段階認証はクライアント側管理を基本にする

## 権限範囲

- 投稿権限
- 閲覧権限
- 広告権限
- 分析閲覧権限

必要最小限の権限のみ付与する。

## 退会/解約時

- 権限解除
- 外部ツール連携解除
- 担当者アカウント削除
- 完了報告

## 不正ログイン時

1. クライアントへ即時連絡
2. パスワード変更依頼
3. 権限確認
4. 外部連携確認
5. 投稿履歴確認

## 保存してはいけない情報

- SNSログインID/パスワード
- 二段階認証コード
- APIキー
- 認証トークン
- 個人アカウントの秘密情報
