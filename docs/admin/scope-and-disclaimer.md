# 業務範囲と免責事項

## ICHI Socialが行うこと

- SNS診断
- 投稿方針設計
- 月間投稿カレンダー
- 投稿企画
- キャプション作成
- 投稿代行または納品
- 月次レポート
- 改善提案

## ICHI Socialが行わないこと

- 成果保証
- 売上保証
- 予約数保証
- SNS広告運用
- 炎上対応
- DM完全代行
- 法務判断
- 高度な撮影/動画制作/デザイン制作

## 免責事項

- SNSプラットフォーム仕様変更への免責
- アカウント停止/制限への免責
- クライアント提供素材の権利責任
- 法令/業界規制に関する最終確認はクライアント側にも必要
- 医療/美容/飲食表現は慎重に確認
- 広告出稿は別途契約
- 撮影、動画制作、デザイン制作の範囲はプランごとに明確にする
