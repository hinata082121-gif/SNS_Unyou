# クライアント素材・制作物・権利管理ルール

## クライアント提供素材

- 写真、動画、ロゴ、メニュー表、スタッフ写真は権利確認後に使用する
- 第三者が写る写真は利用許可を確認する
- お客様の顔写真や口コミは利用許可を確認する

## 制作物の権利

- 制作物の著作権/利用権は契約条件で整理する
- 契約終了後の利用範囲を確認する
- 実績掲載可否を事前確認する

## Canva等のテンプレート

- 利用規約を確認する
- 再配布や二次利用の可否を確認する
- 有料素材の扱いを確認する

## フリー素材

- 商用利用可否を確認する
- クレジット表記要否を確認する
- 出典を記録する

## 禁止事項

- 権利不明素材を使わない
- 無断転載画像を使わない
- 許可のない顧客写真を使わない

## 外注先が素材や制作物に関わる場合

- 外注先に渡す素材は許諾済み素材に限定する
- クライアント秘密情報やSNSログイン情報は渡さない
- 外注先の制作物について、利用範囲、二次利用、実績掲載可否を確認する
- Canva、フリー素材、フォント、BGM、動画素材の利用条件を確認する
- 外注成果物もICHI Social側で権利/品質レビューを行ってからクライアント確認へ進める
