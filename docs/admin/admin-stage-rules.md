# 法務・契約・請求 ステージ管理ルール

## 申込前

- 定義: 提案済みで申込前
- 完了条件: 申込意思確認
- 次アクション: 申込書作成
- 人間確認: 条件確定

## 申込書作成中

- 定義: 申込書下書き作成中
- 完了条件: 下書き完成
- 次アクション: 申込確認依頼
- 人間確認: 金額、期間、範囲

## 申込確認待ち

- 定義: クライアント確認待ち
- 完了条件: 申込内容承認
- 次アクション: 契約確認
- 人間確認: 同意事項

## 契約確認中

- 定義: 契約条件確認中
- 完了条件: 契約条件合意
- 次アクション: 請求書作成
- 人間確認: 専門家確認要否

## 請求書作成中

- 定義: 請求書下書き作成中
- 完了条件: 請求書確認完了
- 次アクション: 請求送付
- 人間確認: 宛名、金額、期限

## 請求済み

- 定義: 請求書送付済み
- 完了条件: 支払期限到来または入金
- 次アクション: 入金確認
- 人間確認: 送付履歴

## 入金待ち

- 定義: 入金確認前
- 完了条件: 入金確認
- 次アクション: 着手可判断
- 人間確認: 銀行明細等

## 入金確認済み

- 定義: 入金確認済み
- 完了条件: 着手条件確認
- 次アクション: 着手可
- 人間確認: 金額一致

## 着手可

- 定義: 申込/契約/支払い/権限の条件が揃った状態
- 完了条件: 納品部門へ引き継ぎ
- 次アクション: オンボーディング
- 人間確認: 最終開始判断

## 契約中

- 定義: 運用中
- 完了条件: 継続/更新/解約判断
- 次アクション: 月次請求
- 人間確認: 範囲変更

## 更新確認中

- 定義: 翌月以降の継続確認中
- 完了条件: 継続可否確認
- 次アクション: 請求または終了処理
- 人間確認: 条件変更

## 解約申請あり

- 定義: 解約希望を受領
- 完了条件: 終了条件確認
- 次アクション: 終了処理
- 人間確認: 未払い、返金、権限

## 終了処理中

- 定義: 権限解除、最終納品、請求確認中
- 完了条件: 終了作業完了
- 次アクション: 終了
- 人間確認: 権限解除

## 終了

- 定義: 契約終了済み
- 完了条件: 記録保存
- 次アクション: なし
- 人間確認: 不要な共有解除

## KPI・経営管理への反映

法務・契約・請求ステージは、売上KPIと請求KPIに反映する。

- `請求済み`: 未請求額から請求済み額へ移動する判断材料
- `入金待ち`: 入金待ち額
- `入金確認済み`: 入金済み額、着手可判断
- `着手可`: 確定MRRまたは初期費用確定の確認対象
- `契約中`: 確定MRR、契約中クライアント数
- `更新確認中`: 翌月売上見込み、解約リスク
- `解約申請あり`: 解約リスク、翌月MRR減少見込み

請求書送付、入金確認、契約判断は自動化せず、人間が確認した値だけを `data/management/client-revenue-template.md` などへ反映する。
