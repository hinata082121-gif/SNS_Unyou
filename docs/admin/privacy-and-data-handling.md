# 個人情報・顧客情報・内部データの取り扱い

## 取り扱う可能性がある情報

- 店舗名
- 担当者名
- メールアドレス
- 電話番号
- SNS URL
- 公式サイトURL
- 請求先情報
- 投稿素材

## 取り扱わない方針の情報

- 顧客名簿
- 予約者一覧
- 決済情報
- SNSログイン情報
- パスワード
- APIキー

## 保存場所

- Google Drive/Docs/Sheets等を使う場合はアクセス権限を制限する
- 不要なローカル保存を避ける

## アクセス権限

- 必要な担当者のみ閲覧可能にする
- 退会/解約時は不要な共有を解除する

## 顧客名簿や予約情報

原則受け取らない。必要がある場合は目的、範囲、保存期間、削除方法を確認する。

## AIツールへの入力

ChatGPT/Hermes/Codex等には、秘密情報、顧客名簿、ログイン情報、認証情報を入力しない。公開情報や匿名化した情報を使う。

## 契約終了後

- 不要なデータを削除または返却
- 権限解除
- 外部共有解除
