# ICHI Social 営業自動化ワークフロー

Hermes Agentは候補作成、JSON整形、営業準備、レビューの補助に使います。営業メール、SNS DM、問い合わせフォーム送信の自動化は行わず、人間が内容と送信可否を確認してから手動で送信します。

## 毎朝9:00

- 今日、人間が確認・手動送信する候補10件を整理する
- スプレッドシートの自動更新は行わない
- ステータス `未検収` または `検収済` を優先する
- 送信済み、返信あり、商談化、反応なしクローズ、除外は対象外
- チェーン、FC、多店舗ブランド、総合SNSしかない店舗は除外する
- 店舗単独SNSまたは問い合わせ導線がある候補を優先する
- 候補の質が低い場合は、無理に10件出さず `候補不足` と報告する
- 店舗ごとに送信前確認ポイント、営業切り口、DM文面案、メール文面案、推奨送信順を出す

## 毎週月曜・水曜 10:30

- 拡大地域からA評価候補をリサーチする
- 対象業態:
  - 美容室
  - ネイル/アイラッシュ
  - 整体
  - カフェ・飲食
- 地域:
  - 川口市
  - 蕨市
  - 戸田市
  - さいたま市南区
  - さいたま市浦和区
  - 東京都北区
  - 東京都板橋区
- 将来的な拡張候補:
  - 足立区
  - 荒川区
  - 練馬区
  - 豊島区
  - さいたま市中央区
- ステータスは `未検収`
- 個人店・小規模店舗を優先する
- チェーン、FC、多店舗ブランド、本部運営色が強い店舗は除外または後回しにする
- JSON保存先:

```text
data/prospects/YYYY-MM-DD-expanded-area-a.json
```

- 保存後、人間に確認を求める
- 人間から明示的に許可があった場合のみ送信スクリプトを実行する

```bash
node scripts/sheets/send-prospects.mjs data/prospects/YYYY-MM-DD-expanded-area-a.json
```

## 平日 9:30

- 毎朝9:00の定期タスク結果を確認する
- 相性スコアAを優先する
- ステータス `未検収` または `検収済` を対象にする
- 店舗ごとに営業切り口を整理する
- 店舗ごとのDM/メール下書きを作る
- 送信は人間が行う

## 平日 18:00

- 今日の送信数を確認する
- 返信あり、商談化、反応なし候補を整理する
- 翌日の次アクションを決める
- 文面の改善案を残す

## 毎週金曜 17:00

- 市場分析、競合分析、営業改善、サービス改善レポートを作成する
- レポート保存先:

```text
docs/reports/marketing/YYYY-MM-DD-weekly-market-analysis.md
```

- 翌週の重点地域、重点業態、検索キーワード、文面改善、サービス改善案を整理する
- 営業メール、SNS DM、問い合わせフォーム送信は行わない
- Googleスプレッドシートの自動更新は行わない

## 禁止事項

- GmailやSNS DMの完全自動送信は初期段階では行わない
- 問い合わせフォーム送信を自動化しない
- スパム的な一斉送信をしない
- 1日10〜20件程度の小ロットから開始する
- 送信前に相手の公式サイト・SNS・問い合わせ可否を確認する
- 問い合わせフォームで営業不可と書かれている場合は送信しない
- 架空の実績や成果保証表現を使わない
- ICHI Socialの営業は「無料簡易診断」を入口にする
