# ICHI Social 営業自動化ワークフロー

Hermes Agentは候補作成、JSON整形、営業準備、レビューの補助に使います。営業メールやSNS DMの自動送信は行わず、人間が内容と送信可否を確認してから手動で送信します。

## 毎週月曜 9:00

- A評価候補を30件作成する
- 対象業態:
  - 美容室
  - ネイル/アイラッシュ
  - 整体
  - カフェ・飲食
- 地域:
  - 初期は川口市周辺
  - 反応が弱ければさいたま市、蕨市、戸田市へ拡大
- ステータスは `未検収`
- JSON保存先:

```text
data/prospects/YYYY-MM-DD-kawaguchi-a-30.json
```

- 保存後、人間確認または送信スクリプトを実行する

```bash
node scripts/sheets/send-prospects.mjs data/prospects/YYYY-MM-DD-kawaguchi-a-30.json
```

## 平日 9:30

- 今日検収する候補10件を選ぶ
- 相性スコアAを優先する
- ステータス `未検収` または `検収済` を対象にする
- 店舗ごとに営業切り口を整理する
- 店舗ごとのDM/メール下書きを作る
- 送信は人間が行う

## 平日 18:00

- 今日の送信数を確認する
- 返信あり、商談化、反応なし候補を整理する
- 翌日の次アクションを決める
- 文面の改善案を残す

## 禁止事項

- GmailやSNS DMの完全自動送信は初期段階では行わない
- スパム的な一斉送信をしない
- 1日10〜20件程度の小ロットから開始する
- 送信前に相手の公式サイト・SNS・問い合わせ可否を確認する
- 問い合わせフォームで営業不可と書かれている場合は送信しない
- 架空の実績や成果保証表現を使わない
- ICHI Socialの営業は「無料簡易診断」を入口にする
