# インフラ管理ステージルール

| ステージ | 定義 | 完了条件 | 次アクション | 人間判断 |
|---|---|---|---|---|
| 未整備 | 手順がない | 管理対象を特定 | 初期設定 | 優先度 |
| 初期設定中 | ツール設定中 | 必要なenv/連携が分かった | ローカル確認 | 実値設定 |
| ローカル確認済み | lint/build等が通る | 検証済み | GitHub連携 | commit/push |
| GitHub連携済み | repo連携済み | push成功 | Vercel確認 | 公開可否 |
| Vercel連携済み | 自動デプロイ可 | Production確認 | Webhook確認 | env設定 |
| Sheets Webhook確認済み | test投入済み | 検証行確認 | Hermes確認 | 実運用投入 |
| Hermesスケジュール確認中 | cron運用中 | missed run監視 | 安定化 | job変更 |
| 安定運用中 | 定期確認で大きな問題なし | レビュー継続 | 改善 | 自動化拡大 |
| 障害対応中 | 問題発生中 | 復旧 | 再発防止 | 停止/復旧判断 |
| 見直し中 | 変更検討中 | 方針決定 | docs更新 | 採用判断 |
