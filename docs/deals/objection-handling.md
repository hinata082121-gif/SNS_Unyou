# 反応別対応テンプレート

## 基本方針

- 強引に追わない
- 相手の事情を尊重する
- 無料診断や後日連絡の選択肢を出す
- 営業不可なら即除外する
- 本部管理なら無理に追わない

## 今は必要ない

```text
ご返信ありがとうございます。
承知しました。今すぐ必要ないとのことですので、こちらから無理にご案内はいたしません。
もし今後、SNS投稿やプロフィール導線を見直したいタイミングがあれば、無料の簡易診断だけでも対応できます。
```

## 予算がない

```text
ご返信ありがとうございます。
ご予算の件、承知しました。無理にご提案するものではありませんのでご安心ください。
もしよろしければ、費用をかけずに見直せる範囲として、プロフィールや投稿テーマの簡易診断だけお渡しできます。
```

## 自分で運用している

```text
ご自身で運用されているとのこと、承知しました。
現在の発信を活かしたうえで、外から見たときに予約導線や強みが伝わりやすいかを簡単に見ることはできます。
必要でしたら、無料の簡易診断だけお送りします。
```

## 本部が管理している

```text
ご返信ありがとうございます。
本部管理とのこと、承知しました。店舗側でSNS運用の判断が難しい場合は、こちらから無理にご案内いたしません。
必要があれば、本部ご担当者様に確認いただける範囲の簡単な資料だけお送りします。
```

## 忙しくて対応できない

```text
お忙しいところご返信ありがとうございます。
今すぐお時間をいただく必要はありません。公開されているSNSやサイトを拝見して、短い簡易診断としてお返しする形であれば、店舗様側の負担は少なく進められます。
```

## 料金を知りたい

```text
ご質問ありがとうございます。
目安として、ライト38,000円/月、スタンダード78,000円/月、プレミアム140,000円/月です。
ただ、必要な支援範囲によって合うプランが変わるため、まずはSNSの状況を簡単に確認してから、無理のない範囲をご案内できればと思います。
```

## 価格が高い

```text
率直なご感想ありがとうございます。
ICHI Socialでは、投稿を増やすだけでなく、投稿方針、プロフィール導線、月次レポート、翌月改善まで含めて設計しています。
もしご予算に合わせる場合は、まずライトプランや単発の改善範囲に絞る形も検討できます。
```

## どこまで含まれますか？

```text
プランによって範囲が変わります。
標準では、投稿方針、投稿企画、キャプション作成、月次レポートなどを中心に対応します。
撮影、高度な動画編集、広告運用、DM完全代行などは標準外のため、必要な場合は事前に範囲を確認します。
```

## 成果は保証されますか？

```text
フォロワー数、売上、予約数の増加を保証するものではありません。
その代わり、伝わり方、予約導線、投稿テーマ、継続運用を整え、毎月改善していく支援としてご提案しています。
```

## 実績を見たい

```text
ご質問ありがとうございます。
現時点では、架空の事例や成果保証のような見せ方はしていません。
代わりに、まずは貴店のSNSを拝見し、どこを整えると伝わりやすくなりそうかを無料の簡易診断としてお渡しできます。
```

## まず診断だけ見たい

```text
もちろんです。
公開されているInstagram、公式サイト、予約導線を拝見して、良い点と改善できそうな点を短く整理します。
診断後に不要であれば、そこで終了で問題ありません。
```

## 営業は受け付けていない

```text
ご連絡ありがとうございます。
営業連絡不可とのこと、承知しました。今後こちらからのご案内は控えます。
お忙しいところご確認ありがとうございました。
```
