# 無料簡易SNS診断フロー

## 目的

返信があった店舗に対して、公開情報をもとに短く具体的な無料簡易SNS診断を作成し、必要に応じて商談へつなげる。

## 診断対象

- Instagramプロフィール
- 投稿内容
- 投稿頻度
- 固定投稿/ハイライト
- 予約導線
- 公式サイト
- Googleビジネスプロフィールが見つかれば参考
- 競合/近隣店舗との見え方の違い

## 診断項目

1. 第一印象
2. 誰向けの店舗か伝わるか
3. 強みがプロフィールに出ているか
4. 予約/問い合わせ導線が分かりやすいか
5. 投稿テーマが整理されているか
6. 初めての人が不安なく来店できるか
7. 改善余地
8. すぐできる改善案3つ
9. ICHI Socialが支援できる範囲

## 進め方

1. 相手から診断許可を得る
2. 公式サイト、Instagram、予約ページを確認する
3. 良い点を先に整理する
4. 改善余地は3点程度に絞る
5. すぐできる改善案を具体化する
6. ICHI Socialで支援できる範囲を控えめに記載する
7. 15〜30分の無料相談へ自然につなげる

## 注意

- 相手の運用を否定しない
- 上から目線にしない
- 断定しない
- 成果保証しない
- 店舗の世界観を尊重する
- 医療/整体領域では治療効果を断定しない
- 美容系では集客保証・予約増加保証を避ける
- 飲食店では予約導線を営業連絡に使えるか確認する
