# 返信後対応フロー

## 目的

返信が来た店舗に対して、売り込み感を抑えながら無料簡易SNS診断へ進める。

## ステージ

- 返信あり
- 診断許可待ち
- 診断作成中
- 診断送付済み
- 商談打診中
- 商談化
- 提案作成中
- 提案済み
- 受注
- 失注
- 保留

## 基本方針

- 返信が来たら即売り込みしない
- まず無料簡易SNS診断の許可を取る
- 相手の公開SNS、公式サイト、予約導線を確認する
- 診断は短く、具体的に、相手がすぐ改善できる内容にする
- 料金案内は相手が興味を示してから行う
- 成果保証・集客保証はしない
- 「改善できる可能性」「整理できる余地」という表現にする
- 営業不可の意思表示があった場合は追わずに終了する

## 初回返信テンプレート

相手が「お願いします」「興味あります」と返した場合:

```text
ご返信ありがとうございます。

まずは売り込みではなく、公開されているInstagramや公式サイトを拝見して、無料の簡易SNS診断として「良い点」と「改善できそうな点」を簡単に整理できればと思います。

確認する内容は、プロフィール、投稿内容、予約導線、初めて見る方への伝わり方が中心です。
診断後に、必要そうであれば運用面でお手伝いできる範囲も軽くご案内します。

差し支えなければ、確認してよいInstagramや公式サイトのURLをお送りいただけますでしょうか。
```

## 診断送付後テンプレート

```text
簡易診断をお送りします。

全体として、店舗の雰囲気や強みは伝わる部分がありました。一方で、初めて見る方に向けて「どんな人に合う店舗か」「予約前に何を知れると安心か」をもう少し整理できる余地がありそうです。

特に改善しやすい点を3つに絞ってまとめました。
もし必要であれば、この内容をもとに15〜30分ほどで、投稿テーマやプロフィール導線の整え方をご一緒に確認できます。
```

## 商談打診テンプレート

```text
診断内容をもとに、もしよろしければ15〜30分ほどオンラインで現状を伺いながら、どこから整えると負担なく進めやすいかをご相談できればと思います。

その場で契約を迫るものではなく、現在のSNS運用状況、投稿に使える素材、予約導線、運用にかけられる時間を確認し、必要な場合だけプランをご提案します。

ご都合の良い曜日や時間帯があれば、いくつか候補をいただけますでしょうか。
```
