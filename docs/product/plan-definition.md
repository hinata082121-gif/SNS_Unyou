# プラン定義

## ライト: 38,000円/月

- 想定顧客: まずSNS運用の土台を整えたい個人店
- 提供目的: 投稿ネタと発信方針を止めない
- 含まれる作業: 投稿企画、キャプション作成、簡易レポート、チャット相談
- 含まれない作業: フル投稿代行、撮影、高度な動画編集、広告運用
- 投稿本数目安: 月8本程度の推奨案
- 月次レポート: 簡易
- 打ち合わせ/確認頻度: 必要時チャット中心の推奨案
- 向いている店舗: 低コストで始めたい店舗
- 向いていない店舗: 投稿作業まで任せたい店舗
- 提案時の言い方: 「まず投稿が止まらない状態を作るプランです」

## スタンダード: 78,000円/月

- 想定顧客: 投稿代行と改善提案まで任せたい店舗
- 提供目的: 継続運用と月次改善を回す
- 含まれる作業: 投稿方針、月間カレンダー、投稿企画、キャプション、投稿代行、月次レポート、改善提案
- 含まれない作業: 撮影、高度な動画編集、広告運用、DM完全代行
- 投稿本数目安: 月16本程度の推奨案
- 月次レポート: 標準
- 打ち合わせ/確認頻度: 月次確認またはチャット中心の推奨案
- 向いている店舗: SNSを任せながら改善したい店舗
- 向いていない店舗: 毎日投稿や高度な制作を求める店舗
- 提案時の言い方: 「投稿作成から代行、改善まで一通り任せる主力プランです」

## プレミアム: 140,000円/月

- 想定顧客: 投稿量、改善提案、戦略相談を強化したい店舗
- 提供目的: 集客/採用/キャンペーンに向けて運用密度を高める
- 含まれる作業: 複数SNS、投稿本数強化、月1回戦略MTG、優先改善提案
- 含まれない作業: 成果保証、広告運用、撮影、高度な動画編集、炎上対応
- 投稿本数目安: 月30本以上の推奨案
- 月次レポート: 強化
- 打ち合わせ/確認頻度: 月1回MTG推奨案
- 向いている店舗: SNSを本格運用したい店舗
- 向いていない店舗: 素材提供や確認体制がない店舗
- 提案時の言い方: 「投稿量と改善施策を増やして、本格的に運用するプランです」
