# 対象顧客定義

## 理想顧客

- 個人店または小規模店舗
- 店舗単独のInstagram/公式サイトがある
- 連絡導線が確認できる
- 営業不可表記がない
- SNSを改善したい意思がある
- 月額38,000円以上の支出を検討できる

## 向いていない店舗

- 全国チェーン、FC、多店舗ブランド
- 本部運営色が強い
- 総合SNSしかない
- 連絡導線がない
- 成果保証を強く求める
- 営業不可/DM不可/問い合わせ不可の記載がある

## 営業優先度Aの条件

店舗単独SNS、公式サイトまたは問い合わせ導線、投稿改善余地、個人店らしさ、SNS上で伝えたい強みがあること。

## 業態別の課題仮説と提案

| 業態 | 課題仮説 | 刺さりやすい提案 |
|---|---|---|
| 美容室 | スタイル/スタッフ/予約導線が分散 | プロフィール改善、スタイル投稿設計 |
| ネイル/アイラッシュ | 写真はあるがメニュー/導線が弱い | 施術例整理、予約前不安の解消 |
| 整体 | 信頼感、流れ、料金が伝わりにくい | 不安軽減投稿、利用の流れ整理 |
| カフェ・飲食 | 世界観はあるが来店導線が弱い | メニュー/空間/営業情報の整理 |
