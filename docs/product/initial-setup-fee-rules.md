# 初期設計費ルール

## 通常価格

初期設計費は通常120,000円。

## 初期3社無料キャンペーン

初期3社限定で初期設計費を無料にするキャンペーンを設定する。ただし無料でも作業範囲が無制限になるわけではない。

## 初期設計で行うこと

SNS診断、投稿方針、トンマナ設計、プロフィール/導線改善案、運用基盤整理、初月投稿テーマ整理。

## 終了条件

3社分の適用が完了した時点、または人間がキャンペーン終了を判断した時点。

## 記載方法

- 提案書: 通常120,000円、初期3社限定で無料適用と明記
- 請求書: 初期設計費とキャンペーン値引きを分けて記載
- 契約書: 適用条件と範囲を明記
