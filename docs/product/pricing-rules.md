# 価格ルール

## 現在の価格

- ライト: 38,000円/月
- スタンダード: 78,000円/月
- プレミアム: 140,000円/月
- 初期設計費: 通常120,000円

## 方針

現時点では価格を変えない。値引きは初期3社キャンペーンを除き、個別判断とする。

## 追加作業

標準範囲を超える投稿本数、動画、撮影、広告、デザイン制作、返信代行などは追加費用または対象外として扱う。

## 見積/請求/契約

見積、申込書、契約書、請求書の金額は本ファイルと整合させる。価格変更時は `docs/deals/`, `docs/admin/`, `docs/product/`, LP文言候補を更新する。

## 自動化しないこと

価格変更、値引き、請求金額変更、契約条件変更は自動で行わない。
