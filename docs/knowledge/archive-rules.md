# アーカイブルール

## アーカイブ対象

- 使わなくなった旧プロンプト
- 古い営業候補レポート
- 古いリサーチレポート
- 過去の提案書/契約書たたき台
- 最新方針と矛盾する手順書

## アーカイブしないもの

- 現行の基本方針
- 契約、請求、法務、品質管理の現行ルール
- 実行中のHermesスケジュールタスクに必要なプロンプト
- トラブル対応に必要な履歴

## 削除しない方がよいもの

- 受注/請求/契約に関わる履歴
- 実運用で使った月次レポート
- エラー原因分析に使えるトラブル記録

## 秘密情報が混入した場合

秘密情報が混入したファイルは通常アーカイブではなく、緊急対応扱いにする。値を再表示せず、種類、場所、影響範囲、初動を記録し、人間がGit履歴対応を判断する。
