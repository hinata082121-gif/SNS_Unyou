# 未追跡ファイルの扱いルール

## 背景

実運用により、`data/prospects/` や `docs/reports/sales/` に未追跡ファイルが残ることがあります。これらは営業候補や実行結果である可能性があるため、CodexやHermesが勝手に削除・コミットしない方針にします。

## 基本ルール

- 未追跡ファイルを勝手に削除しない
- 未追跡ファイルを勝手にコミットしない
- 何のファイルか確認する
- 営業候補JSONは人間確認後にコミットするか判断する
- 実運用レポートは秘密情報がないか確認してから扱う
- `SECRET_TOKEN`、Webhook URLの実値、APIキー、認証情報、口座情報が含まれていないか確認する
- Codex作業対象外なら触らない

## 判断基準

| 種類 | 扱い |
|---|---|
| テンプレート | コミット可 |
| ダミーデータ | コミット可 |
| 実運用候補JSON | 人間確認後 |
| 実クライアント関連レポート | 秘密情報確認後 |
| 秘密情報疑い | コミット禁止、品質部門へ |

## 見直し候補

未追跡ファイルが増える場合は、`.gitignore`、保存先、レポート運用、コミット判断ルールを見直す。
