# 月次運用ガイド

## 月初

- 自社SNS月間カレンダーを作る場合は `self-sns-monthly-calendar-builder.md` を使う
- 当月の重点地域、重点業態、KPI目標を確認する

## 20日

- 月次継続提案レビューの候補日
- クライアントがいる場合は `docs/cs/monthly-success-review.md` と `renewal-proposal-builder.md` を使う
- 継続提案やプラン変更は人間が判断する

## 25日

- 月次請求レビューの候補日
- `docs/admin/billing-checklist.md` と `billing-review.md` を確認する
- 請求書送付、入金確認は人間が行う

## 月末

- 月次経営レポート、月次全体レビュー、月次ドキュメント棚卸しの候補日
- MRR、売上見込み、請求/入金、納品状況、リスク、翌月方針を確認する
- クライアント月次レポートがある場合はCSレビューへ接続する

## 注意

月次運用では数値を推測しない。不明な値は `未入力`、`未集計`、`未取得` と書く。
