# 週次運用ガイド

## 月曜

- 月水リサーチ/リスト更新を確認する
- 契約中クライアントがいる場合は週次クライアント運用レビューを確認する
- 前週の候補不足や除外理由を営業ルールへ反映する

## 水曜

- 月水リサーチ/リスト更新を確認する
- 新規候補JSONに秘密情報や架空URLがないか確認する
- スプレッドシート投入は人間確認後に行う

## 金曜

- 週次市場/競合分析を確認する
- 自社SNS投稿案や週次レビューがある場合は内容を確認する
- 公開前には品質管理のチェックリストを使う

## 土曜

- 週次AI運用監査を実施する場合は `weekly-ai-ops-audit.md` を使う
- 秘密情報混入、成果保証表現、禁止自動化違反を確認する

## 日曜

- 週次KPIレビュー、週次全体レビュー、週次ナレッジレビューの候補日
- 追加/更新されたdocs、prompts、reportsを棚卸しする
- 翌週の重点地域、重点業態、優先タスクを決める

## 人間が判断すること

- 営業送信、SNS投稿、請求送付、契約判断、価格変更、クライアント連絡
- スケジュールタスクの新規登録/修正/削除
- 未追跡ファイルをコミットするかどうか
