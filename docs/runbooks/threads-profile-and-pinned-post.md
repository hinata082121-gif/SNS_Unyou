# Threadsプロフィール・固定投稿 手動設定Runbook

## 方針

今回確認したThreads API投稿仕様では、プロフィール文の編集と固定投稿の自動固定を本番自動化対象にしない。
Threadsアプリまたは管理画面で人間が手動設定する。

## プロフィール文案

```text
小規模店舗・個人事業主向けに
SNSの見え方と予約導線を整理します。

プロフィール・固定投稿・発信内容を
無理なく続けられる形へ。

実例やチェックリストはInstagramで発信中
Instagram：未設定
```

Instagramユーザー名が決まるまでは、架空のhandleを入れない。

## 固定投稿案

```text
はじめまして。ICHI Socialです。

小規模店舗・個人事業主の方に向けて、

・プロフィールを見ても内容が伝わりにくい
・何を投稿すればよいか決まらない
・投稿しても予約や問い合わせにつながらない
・SNS運用に時間をかけられない

といった悩みを整理するサポートを行っています。

このThreadsでは、すぐ確認できるSNS改善ポイントや、発信を続けやすくする考え方を投稿します。

Instagramでは、図解・チェックリスト・保存用コンテンツを中心に掲載していきます。

詳しく見たい方はプロフィールからInstagramをご覧ください。
```

## 手動設定手順

1. Threadsアプリでプロフィール編集を開く
2. プロフィール文案を貼り付ける
3. Instagram handleが未設定の場合はInstagram行を未設定のままにする
4. 固定投稿案をThreadsへ手動投稿する
5. 投稿後、Threadsアプリで固定する
6. 固定後、プロフィールから固定投稿とInstagram導線が自然に見えるか確認する

## 確認項目

- 架空のInstagram handleを入れていない
- 誇大表現や成果保証がない
- プロフィールだけで対象者と支援内容が分かる
- 固定投稿だけでICHI Socialの役割が分かる
- Threads投稿からInstagramへの誘導が過剰ではない

## 自動化禁止

- API仕様未確認のプロフィール自動編集
- API仕様未確認の固定投稿自動操作
- Threads本文やAPIレスポンス全文のログ保存
- トークン、User ID、App Secretの表示
