# 優先順位マトリクス

## 評価軸

- 売上への近さ
- 顧客対応の緊急度
- リスクの大きさ
- 自動化への影響
- 人間判断の必要性

## 分類

### 今すぐやる

- 返信あり対応
- 商談日程調整
- 入金前着手の確認
- 営業不可先への誤送信リスク対応

### 今日中にやる

- 営業候補の検収
- 送信予定候補の最終確認
- 無料SNS診断の下書き確認
- クライアント確認待ちへの対応

### 今週中にやる

- 市場/競合分析の反映
- 文面改善
- KPI入力
- 月次レポート下書き

### 保留

- 将来タスク登録
- LP細部改善
- 新ツール導入検討

### やらない

- 自動送信
- 価格変更の自動決定
- 秘密情報の自動入力
- 法務/税務判断の自動化

## 例

- 返信あり対応は優先度高
- 営業候補の検収は高
- LP細部改善は中
- 将来タスク登録は低〜中
- 自動送信はやらない
