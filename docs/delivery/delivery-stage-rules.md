# 納品ステージ管理ルール

## 受注

- 定義: 契約意思が確認できた状態
- 完了条件: プラン、開始時期、支払い条件を確認
- 次アクション: オンボーディング日程調整

## オンボーディング待ち

- 定義: キックオフ前の準備中
- 完了条件: ヒアリング項目と必要素材を共有
- 次アクション: 初回ヒアリング

## ヒアリング完了

- 定義: 店舗情報、素材、確認フローを把握済み
- 完了条件: 未確認事項を整理
- 次アクション: 初期設計

## 初期設計中

- 定義: プロフィール導線や投稿方針を整理中
- 完了条件: 運用方針案を作成
- 次アクション: 投稿方針作成

## 投稿方針作成中

- 定義: 投稿カテゴリ、トーン、月間テーマを作成中
- 完了条件: クライアント確認へ出せる状態
- 次アクション: 月間カレンダー作成

## 月間カレンダー作成中

- 定義: 投稿日、テーマ、素材、ステータスを整理中
- 完了条件: 月間投稿カレンダー作成
- 次アクション: クライアント確認

## クライアント確認中

- 定義: 投稿案やカレンダーを確認依頼中
- 完了条件: 承認または修正依頼を受領
- 次アクション: 修正または投稿準備

## 修正中

- 定義: クライアント修正依頼に対応中
- 完了条件: 修正版を提出
- 次アクション: 再確認

## 投稿準備中

- 定義: 承認済み投稿を予約/納品準備中
- 完了条件: 投稿予定または納品完了
- 次アクション: 運用中

## 運用中

- 定義: 月間運用を実施中
- 完了条件: 当月投稿と確認対応を進行
- 次アクション: 月次レポート作成

## 月次レポート作成中

- 定義: 実施内容と数値を整理中
- 完了条件: 月次レポート提出
- 次アクション: 継続提案

## 継続提案中

- 定義: 翌月方針と改善案を提案中
- 完了条件: 翌月運用方針に合意
- 次アクション: 次月カレンダー作成

## 解約/終了

- 定義: 契約終了または運用終了
- 完了条件: 権限解除、最終レポート、終了確認
- 次アクション: 終了記録

## KPI・経営管理への反映

納品ステージは、納品KPIと作業負荷の確認に反映する。

- `月間カレンダー作成中`: 投稿カレンダー作成数
- `クライアント確認中`: 投稿確認待ち件数
- `修正中`: 修正負荷、遅延リスク
- `投稿準備中`: 投稿予定数
- `運用中`: 契約中クライアント数
- `月次レポート作成中`: 月次レポート作成数
- 素材不足が原因で止まっている場合: 素材待ち件数

週次の `weekly-client-operation-review` とKPIレビューで、素材待ち、確認待ち、月次レポート作成中、遅延リスクを確認する。
