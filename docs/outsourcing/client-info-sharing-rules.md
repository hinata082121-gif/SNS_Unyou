# クライアント情報共有ルール

## 共有してよい情報

- 公開されている公式サイト/SNS
- 業態、地域、投稿テーマ
- 匿名化した課題
- 許諾済み素材

## 匿名化して共有すべき情報

- 商談メモ
- CSフィードバック
- 月次レポート所感
- 投稿改善方針

## 共有禁止情報

- 顧客個人情報
- 予約情報
- 顧客名簿
- SNSログイン情報
- 売上や契約の未公開情報
- APIキー、SECRET_TOKEN、Webhook URL
- 口座情報、登録番号

## 店舗名を出す場合

公開情報の確認や店舗らしさの反映に必要な場合のみ共有する。共有先、目的、保存場所、削除タイミングを確認する。

## SNS URLを共有する場合

閲覧目的に限定し、ログインや投稿操作は依頼しない。

## スクリーンショット

無断掲載や二次利用を避ける。内部作業用でも不要な個人情報が写っていないか確認する。
