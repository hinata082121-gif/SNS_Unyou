# 外注管理ステージルール

| ステージ | 定義 | 完了条件 | 次アクション | 人間判断 |
|---|---|---|---|---|
| 外注不要 | 内製で対応可能 | 負荷に問題なし | 継続監視 | 外注開始要否 |
| 外注候補検討中 | 切り出し業務を検討 | 業務範囲が整理済み | 募集準備 | 任せる範囲 |
| 募集準備中 | 募集文/条件を作成 | 条件が確認済み | 募集判断 | 掲載可否 |
| 候補者確認中 | 応募者を確認 | 基準評価済み | トライアル | 採用候補可否 |
| トライアル中 | 試験業務を実施 | 成果物レビュー済み | 契約条件確認 | 継続可否 |
| 契約条件確認中 | 報酬/納期/権利を確認 | 条件合意 | 稼働開始 | 契約判断 |
| 稼働中 | 依頼中 | 納品/検収 | レビュー | 支払い/継続 |
| レビュー中 | 成果物/対応を評価 | スコアカード更新 | 継続可否判断 | 評価 |
| 継続可 | 再依頼可能 | 次回条件確認 | 継続依頼 | 単価/範囲 |
| 注意 | 品質/納期/守秘に懸念 | 改善確認 | 条件付き継続 | 停止要否 |
| 停止 | 新規依頼停止 | 未払い/未納品整理 | 終了処理 | 再開可否 |
| 終了 | 取引終了 | オフボーディング完了 | 記録保管 | 再依頼可否 |
