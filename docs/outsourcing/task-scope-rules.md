# 外注可能業務・外注禁止業務

## 外注可能

- 投稿案の下書き
- キャプション案の下書き
- デザイン初稿
- ショート動画台本案
- リサーチ補助
- レポート整理補助
- 誤字脱字チェック
- 投稿カレンダー補助

## 外注禁止

- クライアントへの直接連絡
- 営業送信
- SNS投稿操作
- SNSログイン
- 請求書送付
- 契約判断
- 価格変更判断
- 法務/税務判断
- 秘密情報入力
- 顧客名簿/予約情報の取り扱い
- 成果保証表現の追加
- 実績/数値の捏造

## 切り出し条件

- 目的、成果物、納期、品質基準が明確である
- 使用してよい情報と禁止情報が分かれている
- ICHI Social側で内部レビューと人間承認ができる
- クライアントへの提出前に品質管理レビューを挟める
