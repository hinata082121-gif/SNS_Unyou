# 外注先向け秘密保持ルール

## 秘密情報の定義

公開されていないクライアント情報、運用情報、売上情報、契約情報、ログイン情報、APIキー、Webhook URL、SECRET_TOKEN、口座情報、個人情報など。

## 渡してよい情報

- 公開サイト/SNS URL
- 匿名化した課題
- 業態、地域、投稿目的
- 許諾済み素材
- ダミー情報

## 渡してはいけない情報

- SNSログイン情報
- APIキー
- Webhook URLの実値
- SHEETS_SECRET_TOKEN
- 顧客名簿/予約情報
- 売上などの未公開情報
- 口座情報
- 個人情報

## 匿名化

店舗名が不要な作業では、業態、地域、ターゲット、課題だけを共有する。実在店舗のスクリーンショットを共有する場合は、必要性と権利を確認する。

## AIツール利用時の注意

外注先がAIツールを使う場合も、秘密情報、ログイン情報、顧客情報、未公開情報を入力しない。AI出力は事実確認し、成果保証表現を除去する。

## 作業終了後

不要なファイルを削除し、共有リンクや権限を解除する。漏えい疑いがある場合は値を再表示せず、種類と影響範囲だけを報告する。
