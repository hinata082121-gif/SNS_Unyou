# 外注成果物 品質チェックリスト

## 共通

- [ ] 目的に合っている
- [ ] クライアントらしさがある
- [ ] 成果保証表現がない
- [ ] 業態別表現リスクがない
- [ ] 誤字脱字が少ない
- [ ] 引用/出典が必要な情報に出典がある
- [ ] 権利リスクがない
- [ ] 秘密情報が混入していない
- [ ] AIっぽすぎない
- [ ] 修正しやすい形式である

## キャプション

- [ ] 冒頭で伝える内容が明確
- [ ] CTAが自然
- [ ] 煽りすぎていない

## 投稿企画

- [ ] 投稿目的と想定読者が明確
- [ ] 投稿テーマが偏りすぎていない

## デザイン

- [ ] 可読性がある
- [ ] 素材利用権に問題がない
- [ ] ブランドトーンに合う

## ショート動画台本

- [ ] 冒頭フックが自然
- [ ] 尺に収まる
- [ ] 断定表現が強すぎない

## リサーチ

- [ ] 出典URLがある
- [ ] 事実と推測が分かれている

## 月次レポート補助

- [ ] 未取得データを未取得と書いている
- [ ] 数値を誇張していない
