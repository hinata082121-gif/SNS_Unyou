# 外注/採用基準

## 共通基準

- 小規模店舗の事情を理解し、上から目線の表現を避けられる
- 納期を守り、遅れそうな場合に早めに連絡できる
- 守秘意識があり、秘密情報やログイン情報を扱わない方針を理解できる
- AI利用時に事実確認、権利、秘密情報に注意できる
- 成果保証、集客保証、売上保証に見える表現を避けられる
- 医療/整体/美容/飲食の表現注意を理解できる
- 修正依頼を冷静に受け取り、改善できる

## SNS運用理解

- 投稿目的、ターゲット、CTAを分けて考えられる
- 投稿ネタを業態や店舗らしさに合わせて作れる
- プロフィール導線、固定投稿、ハイライト、予約導線の基本を理解している

## 文章品質

- 読みやすく自然な日本語が書ける
- 一斉送信感、誇張、煽りを避けられる
- 不明な情報を断定しない

## 著作権/素材権利

- 無断転載やスクリーンショットの扱いに注意できる
- Canvaやフリー素材の利用条件を確認できる
- 第三者が写る素材の利用可否を確認できる

## 採用しない方がよいケース

- 守秘義務やログイン情報の扱いを軽視する
- 実績や数値を盛る
- 成果保証表現を使いたがる
- 連絡が極端に遅い
- 無断再委託を行う可能性が高い
- 実在店舗を批判する表現が多い
