# トライアル課題テンプレート

## 課題の目的

外注候補者の品質、守秘意識、表現リスク理解、納期対応を確認する。

## 想定業態

ダミー店舗。実在店舗情報は使わない。

## ダミー店舗設定

- 店舗名: サンプルサロン
- 業態: 美容室
- 地域: 架空地域
- 強み: 丁寧なカウンセリング、落ち着いた空間
- 課題: SNS投稿が不定期、プロフィール導線が弱い

## 作ってもらうもの

- 投稿テーマ案5件
- キャプション案2件
- 注意表現チェック

## 提出形式

MarkdownまたはGoogleドキュメント相当の形式。

## 評価基準

- 目的理解
- 小規模店舗への理解
- 文章品質
- 成果保証表現の回避
- 権利/秘密情報への配慮
- 修正しやすさ

## 注意表現

集客保証、売上保証、必ず効果が出るなどは使わない。

## 禁止

- 秘密情報を使わない
- 実在店舗情報を使わない
- 実績や数値を作らない
