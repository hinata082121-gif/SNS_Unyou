# 業務依頼書テンプレート

これは業務委託条件を整理するたたき台です。法的確定文書ではなく、必要に応じて専門家確認を行います。

| 項目 | 内容 |
|---|---|
| 依頼日 | YYYY-MM-DD |
| 依頼者 | ICHI Social |
| 受託者 | ダミー氏名/屋号 |
| 業務名 | 例: Instagram投稿キャプション下書き |
| 業務内容 | 具体的な作業範囲 |
| 成果物 | Markdown、Canvaリンク、動画ファイルなど |
| 納期 | YYYY-MM-DD HH:mm |
| 報酬 | ダミー金額。実額は人間確認 |
| 支払期日 | 検収完了後の条件を記載 |
| 検収条件 | 品質基準、提出形式、確認期限 |
| 修正回数 | 例: 軽微な修正2回まで |
| 使用素材 | 許諾済み素材のみ |
| 使用禁止情報 | ログイン情報、顧客情報、秘密情報 |
| 秘密保持 | 業務上知った情報を第三者に開示しない |
| 権利の扱い | 成果物の利用範囲を明記 |
| 再委託可否 | 原則不可。必要時は事前承認 |
| 連絡方法 | ダミー連絡手段 |
| 注意事項 | 成果保証表現、無断転載禁止 |
| 署名/同意欄 | 依頼者/受託者 |
