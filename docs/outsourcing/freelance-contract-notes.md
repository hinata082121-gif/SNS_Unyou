# フリーランス業務委託時の注意メモ

この文書は法的確定文書ではなく、運用メモです。契約、税務、労務、フリーランス法対応は必要に応じて専門家確認を前提にします。

## 確認項目

- 業務内容の明示
- 報酬額
- 支払期日
- 納期
- 検収条件
- 修正回数
- 素材/制作物の権利
- 秘密保持
- 再委託の扱い
- 中途終了
- ハラスメント防止
- 連絡手段
- 追加作業の扱い
- 仕様変更時の扱い

## 条件の残し方

業務依頼ごとに、書面または電磁的方法で条件を残す。口頭だけで依頼しない。報酬、納期、成果物、検収条件、修正回数、権利、秘密保持は最低限明記する。

## 人間判断

採用、契約、報酬、支払い、終了判断は人間が行う。Hermes/Codexは下書きとチェックリスト作成までに留める。
