# 品質監査ステージ管理ルール

## 未レビュー

- 定義: AI生成後、未確認
- 完了条件: AI一次チェックへ進む
- 次アクション: レビュー実行
- 人間判断: 不要

## AI一次チェック済み

- 定義: Hermes/Codexでチェック済み
- 完了条件: リスク分類完了
- 次アクション: 人間確認
- 人間判断: 必要に応じて

## 人間確認待ち

- 定義: 人間の承認待ち
- 完了条件: 承認または差し戻し
- 次アクション: 承認/修正
- 人間判断: 必須

## 修正中

- 定義: 指摘事項を修正中
- 完了条件: 再レビュー可能
- 次アクション: 再チェック
- 人間判断: 修正方針

## 承認済み

- 定義: 人間が送付/公開可と判断
- 完了条件: 記録
- 次アクション: 人間が送付/公開
- 人間判断: 完了

## 差し戻し

- 定義: 修正が必要
- 完了条件: 修正案作成
- 次アクション: 修正中
- 人間判断: 必要

## 送付不可

- 定義: 営業/提案/契約資料として使えない
- 完了条件: 停止理由記録
- 次アクション: 作り直し
- 人間判断: 必須

## 公開不可

- 定義: SNS/広報として公開できない
- 完了条件: 停止理由記録
- 次アクション: 作り直し
- 人間判断: 必須

## インシデント記録済み

- 定義: 重大リスクをログ化済み
- 完了条件: 再発防止策記録
- 次アクション: 監査
- 人間判断: 必須
