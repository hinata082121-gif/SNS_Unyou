# 自動化してはいけない作業の境界線

## 自動化禁止

- 営業メール送信
- SNS DM送信
- 問い合わせフォーム送信
- SNS投稿
- クライアントへの自動連絡
- 請求書送付
- 入金確認
- 契約判断
- 価格変更
- 法務判断
- 税務判断
- SNS権限操作
- パスワード保存
- 秘密情報入力
- 自動修正後の自動公開
- 自動修正後の自動送信
- 外注先への自動依頼
- 外注候補の自動採用判断
- 業務委託契約の自動判断
- 外注費の自動支払い
- クライアント情報の自動共有
- モデルの自動変更
- 本番プロンプトの自動大幅変更
- AI改善案の自動本番反映

## Hermes/Codexに任せてよい

- 下書き
- レポート
- チェックリスト
- 改善案
- 分類
- 要約
- 確認ポイント作成
- 人間承認前提の資料作成

## 判断基準

外部に影響する操作、法務/税務/契約判断、金銭や権限に関わる操作は人間承認が必要。

AI運用改善部門でも、自動送信、自動投稿、自動請求、自動契約、自動価格変更、自動モデル変更、自動プロンプト本番反映は行わない。
