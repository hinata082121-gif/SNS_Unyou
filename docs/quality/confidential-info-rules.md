# 秘密情報・認証情報の扱いルール

## 禁止情報

- SHEETS_SECRET_TOKEN
- SHEETS_WEBHOOK_URLの実値
- APIキー
- OAuth URL
- 認証コード
- Gmail app password
- SNSログイン情報
- 銀行口座番号
- 適格請求書登録番号の実値
- クライアント個人情報
- 顧客名簿
- 予約情報
- 未公開売上情報

## AIに入れてよい情報

- 公開済みURL
- 公開プロフィール
- 匿名化した課題
- ダミーデータ
- サンプル表記された内容

## AIに入れてはいけない情報

ログイン情報、認証情報、秘密トークン、実在の口座番号、顧客名簿、予約情報、未公開の個人情報。

## レポート保存時の注意

秘密情報を値として保存しない。疑わしい場合は種類だけを書き、値はマスキングする。

## Gitにコミットしてはいけない情報

.env実値、Webhook実URL、SECRET_TOKEN、APIキー、認証コード、口座番号、登録番号、個人情報。

## エラー時の初動

1. 共有停止
2. 該当ファイルを特定
3. 値を削除またはマスキング
4. 必要ならトークン/パスワード変更
5. インシデントログに記録

## 漏えい疑い時の対応

人間が影響範囲、再発防止、外部報告の要否を判断する。
