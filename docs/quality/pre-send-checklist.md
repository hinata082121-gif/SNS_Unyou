# 営業送信前チェックリスト

対象: DM、メール、問い合わせフォーム文面。

- 店舗名が正しいか
- 店舗URL/SNSが一致しているか
- 営業不可/DM不可/問い合わせ不可表記がないか
- チェーン/FC/本部運営ではないか
- 連絡導線が営業連絡に使えるものか
- 予約専用フォームに営業連絡を送ろうとしていないか
- 一斉送信感がないか
- 売り込みが強すぎないか
- 無料SNS診断への導線が自然か
- 成果保証表現がないか
- SECRET_TOKENやWebhook URL等が混入していないか

## 送信不可の例

- 営業不可が明記されている
- 予約専用フォームしかない
- チェーン/本部運営の可能性が高い
- 店舗名やURLが一致しない
- 秘密情報が含まれる
