# AI生成物レビュー基本ルール

## 対象

- 営業DM
- 営業メール
- 問い合わせフォーム文面
- 無料SNS診断
- 商談メモ
- 提案書
- 見積
- 契約書たたき台
- 請求書たたき台
- 投稿企画
- キャプション
- ショート動画台本
- 月次レポート
- 市場/競合分析
- KPI/経営レポート

## チェック項目

- 事実と推測が分かれているか
- 不明情報を断定していないか
- 架空実績がないか
- 架空数値がないか
- 成果保証に見えないか
- 業態別の表現注意に反していないか
- 秘密情報が含まれていないか
- 自動化してはいけない作業を促していないか
- 人間確認が必要な箇所が明記されているか

## 判定

- OK: そのまま人間確認へ進める
- 要修正: 軽微な修正後に再確認
- 要人間確認: 人間が判断するまで送付/公開しない
- 停止: 送付/公開不可。必要に応じてインシデント記録

## AI運用改善部門への接続

AI生成物レビューで同じ問題が繰り返される場合は、`docs/ai-ops/output-evaluation-scorecard.md` と `docs/ai-ops/failure-analysis-rules.md` を使い、プロンプト、モデル、コンテキスト、テストケースの改善対象として記録する。
