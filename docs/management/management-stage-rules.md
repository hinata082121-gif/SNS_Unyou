# 経営管理ステージ運用ルール

## 立ち上げ

- 状態: 受注前で仕組みを整備中
- 見るべきKPI: 候補作成数、検収済数、送信数
- 優先アクション: 営業候補品質の改善
- 注意点: 実績を誇張しない
- 次ステージへの条件: 返信が安定して発生する

## 営業検証中

- 状態: 営業文面、地域、業態を検証中
- 見るべきKPI: 返信率、除外率、業態別/地域別反応
- 優先アクション: 文面とターゲティング改善
- 注意点: 送信量より質を優先
- 次ステージへの条件: 商談化が発生する

## 初回商談獲得

- 状態: 初回の相談/診断につながった
- 見るべきKPI: 診断許可数、商談実施数
- 優先アクション: 診断と商談準備
- 注意点: 売り込みすぎない
- 次ステージへの条件: 提案書作成

## 初回受注前

- 状態: 提案済みで受注待ち
- 見るべきKPI: 提案数、受注率、見込みMRR
- 優先アクション: 契約条件と不安解消
- 注意点: 成果保証しない
- 次ステージへの条件: 申込意思確認

## 初回受注後

- 状態: 初回クライアントの立ち上げ中
- 見るべきKPI: MRR、納品遅延、作業負荷
- 優先アクション: オンボーディングと初月納品
- 注意点: 作業範囲を広げすぎない
- 次ステージへの条件: 初月レポート提出

## 3社獲得

- 状態: 複数クライアントを並行運用
- 見るべきKPI: MRR、粗利、作業時間、継続率
- 優先アクション: 標準化と外注可否検討
- 注意点: 納品品質低下
- 次ステージへの条件: 継続運用が安定

## 継続運用

- 状態: 毎月の営業/納品/請求が回っている
- 見るべきKPI: 継続率、MRR、月次レポート作成数
- 優先アクション: 改善提案と解約予防
- 注意点: 作業過多
- 次ステージへの条件: 拡大余力がある

## 拡大検討

- 状態: 地域、業態、外注、商品拡張を検討
- 見るべきKPI: 粗利、作業負荷、受注率、LTV見込み
- 優先アクション: 採算の良い型を伸ばす
- 注意点: 固定費増加
- 次ステージへの条件: 人間が判断する
