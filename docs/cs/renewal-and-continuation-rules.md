# 継続提案ルール

## タイミング

- 30日目レビュー後
- 月次レポート送付後
- 契約更新前
- 解約リスクが見えた時

## 月次レポート後の流れ

1. 実施内容と変化を整理
2. クライアントの反応を記録
3. 翌月改善案を提示
4. 継続/縮小/変更の必要性を確認

## 継続しやすい伝え方

成果保証ではなく、伝わり方、導線、投稿品質、継続運用を整える支援として伝える。

## 解約リスクがある場合

不満や不安を責めず、期待値、作業範囲、予算、確認負荷を整理する。

## 提案パターン

- プラン維持提案
- プラン変更提案
- 一時停止/縮小提案
- 終了する場合の円満対応
