# アップセル/クロスセル提案ルール

## 提案例

- ライトからスタンダード
- スタンダードからプレミアム
- 投稿本数追加
- ショート動画台本追加
- 月次レポート強化
- プロフィール改善追加
- キャンペーン投稿設計
- Googleビジネスプロフィール改善提案

## 注意

- 押し売りしない
- 相手の課題に紐づける
- 数値保証しない
- 作業負荷と予算感を確認する
- まず既存プランの満足度を確認する

## 判断

アップセルは、ヘルススコアAまたはBで、課題と予算が明確な場合に検討する。ヘルススコアCの場合は、まず既存プランの不安解消を優先する。

## 商品開発部門との接続

アップセル/クロスセルを検討する際は、`docs/product/upsell-path.md` と `docs/product/option-menu.md` を参照する。新しいオプションや価格は検討案として扱い、自動で提案・契約・請求に反映しない。
