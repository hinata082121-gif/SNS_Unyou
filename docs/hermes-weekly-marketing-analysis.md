# Hermes 週次市場・競合分析

## 1. 目的

ICHI Socialの営業効率、営業精度、サービス品質を高めるため、Hermes Agentで週次の市場分析・競合分析を行います。

## 2. 実行タイミング

毎週金曜17:00を推奨します。

## 3. 分析対象

- SNS運用代行市場
- 小規模店舗向けSNS支援
- 地域密着型Web/SNS支援
- フリーランスSNS代行
- 美容室、ネイル/アイラッシュ、整体、カフェ・飲食向け支援

## 4. レポート保存先

```text
docs/reports/marketing/YYYY-MM-DD-weekly-market-analysis.md
```

## 5. 活用方法

- 翌週の営業候補選定に反映
- DM/メール文面改善に反映
- LP改善に反映
- Instagram投稿テーマに反映
- 無料SNS診断の内容改善に反映
- 料金プランや初期費用キャンペーンの見直しに反映
- 週次KPIレビューに反映し、反応が高い地域/業態、除外が多い候補、文面改善履歴、LP/サービス改善施策として整理する
- KPIが未入力の場合は市場分析だけで判断せず、翌週の検証仮説として扱う

## 6. 禁止事項

- 自動送信しない
- スプレッドシートを勝手に更新しない
- 秘密情報を表示しない
- 競合情報を推測で書かない
- 競合を誹謗中傷しない
- 営業メール、SNS DM、問い合わせフォーム送信を行わない

```text
これは通常の依頼ではなく、Hermes Agentのスケジュールタスクとして登録してください。

タスク名:

- 不明な情報は推測せず「不明」と書く
```
