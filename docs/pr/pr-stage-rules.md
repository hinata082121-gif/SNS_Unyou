# 自社SNS・広報ステージ管理ルール

## 準備中

- 定義: 発信方針とプロフィールを準備中
- 完了条件: ブランドメッセージとプロフィール案がある
- 次アクション: プロフィール整備
- 注意点: 架空実績を書かない

## プロフィール整備中

- 定義: 各SNSプロフィールとリンク導線を整える
- 完了条件: CTAと固定投稿案が決まる
- 次アクション: 投稿案作成
- 注意点: 成果保証しない

## 投稿案作成中

- 定義: 投稿テーマ、本文、動画台本を作成中
- 完了条件: 投稿前チェックが完了
- 次アクション: 初期投稿開始
- 注意点: 実在店舗を無断利用しない

## 初期投稿開始

- 定義: 実績なし前提のノウハウ投稿を開始
- 完了条件: 初期30日投稿を実施
- 次アクション: 週次改善
- 注意点: 営業色を強くしすぎない

## 週次改善中

- 定義: 投稿反応と営業接続を確認中
- 完了条件: 翌週テーマが決まる
- 次アクション: 問い合わせ導線改善
- 注意点: 反応を推測で判断しない

## 問い合わせ導線改善中

- 定義: 無料SNS診断への導線を改善中
- 完了条件: CTAとリンク導線が明確
- 次アクション: 事例作成準備
- 注意点: 強引な誘導にしない

## 事例作成中

- 定義: 実績またはサンプル改善例を作成中
- 完了条件: 許可やサンプル表記を確認
- 次アクション: 実績掲載許可待ち
- 注意点: 架空事例を実績にしない

## 実績掲載許可待ち

- 定義: クライアント許可確認中
- 完了条件: 掲載範囲が明確
- 次アクション: 継続運用
- 注意点: 許可なし公開禁止

## 継続運用中

- 定義: 投稿と改善を継続中
- 完了条件: 週次レビューを継続
- 次アクション: 成長施策ログへ反映
- 注意点: 自動投稿しない
