# 自社SNS・広報部門 概要

## 目的

ICHI Social自身のSNS発信、広報、認知獲得、信頼形成、営業補助コンテンツ、ショート動画、投稿カレンダー、発信テーマ、事例風コンテンツを標準化する。

## 対象チャネル

- Instagram
- X
- TikTok
- YouTube Shorts
- note またはブログ

## 役割

- 小規模店舗向けにSNS運用の考え方を発信する
- 無料SNS診断への自然な導線を作る
- 営業前後の信頼材料を増やす
- ICHI Socialの運用方針や制作プロセスを見える化する
- 実績がない段階でも役立つノウハウを蓄積する

## 営業との接続

営業DM/メール後にプロフィールや投稿を見られても、何を支援するサービスか伝わる状態にする。営業色を強くしすぎず、無料SNS診断を入口にする。

## マーケティング部門との接続

週次市場・競合分析から得た訴求、地域、業態別の示唆を投稿テーマに反映する。

## KPI・経営管理部門との接続

投稿本数、反応、問い合わせ導線、反応がよいテーマ、営業への補助効果を成長施策ログに残す。

## Hermesに任せること

- 投稿カレンダー案
- 投稿案
- ショート動画台本
- プロフィール改善案
- 週次レビュー下書き
- サンプル改善例の下書き

## 人間が判断すること

- 投稿可否
- 実績掲載可否
- 表現リスク
- CTAの強さ
- 実際の投稿操作

## 自動化しないこと

- SNSへの自動投稿
- 外部SNSアカウント操作
- クライアントへの自動連絡
- 営業メール送信
- SNS DM送信
- 問い合わせフォーム送信
- 架空実績作成
- 架空数値作成
- 実績の無断掲載
- スクリーンショットの無断利用
- 秘密情報や認証情報の自動入力
