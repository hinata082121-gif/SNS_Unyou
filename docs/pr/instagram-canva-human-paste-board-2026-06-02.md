# Instagram Canva人間貼り付けボード 2026-06-02

## 目的

人間がCanva上で迷わず貼り付け制作できるよう、コピー元、貼り付け先、操作手順、停止条件を整理する。

## 基本手順

1. CanvaでInstagram投稿用テンプレートを開く。
2. 投稿IDごとにページ数またはカット数を作る。
3. `docs/pr/instagram-canva-copy-pack-2026-06-02.md` から該当テキストを貼る。
4. `docs/pr/instagram-canva-slide-map-2026-06-02.md` を見て配置する。
5. `docs/pr/instagram-canva-asset-checklist-2026-06-02.md` を見て素材を入れる。
6. 書き出し前に投稿前チェックを行う。
7. 書き出し後も、Instagram投稿は人間が別途判断する。

## 投稿別の貼り付け先

### P1

- 表紙: 「小さなお店のSNSを、続けやすく整える。」
- 本文: 2〜5枚目へ1メッセージずつ
- CTA: 6枚目下部

### P2

- 表紙: 「投稿しているのに、伝わり方で損しているかも。」
- 代替案: 「投稿しているのに、伝わり方で迷いやすいかも。」
- 本文: よくある悩みを1枚1つ
- CTA: 6枚目下部

### P3

- 表紙: 「無料SNS診断で見るポイント」
- 本文: 診断ポイントを番号順
- CTA: 6枚目下部
- 注意: 自動化相談は補助扱い

### R1

- サムネ: 「毎日投稿の前に、整える3つ」
- 冒頭: 0〜2秒
- 本文: プロフィール、固定投稿、予約導線
- CTA: 12〜15秒

### R2

- サムネ: 「予約方法、すぐ見つかりますか？」
- 冒頭: 0〜2秒
- 本文: 見つけにくいポイント
- CTA: 最後に控えめ

## Canvaから書き出した後に確認する項目

- 文字がスマホで読める
- 1枚目/サムネが小さく表示されても意味が分かる
- CTAが強すぎない
- 成果保証に見える表現がない
- 実在店舗や営業先の情報が入っていない
- 書き出しファイル名に個人情報や営業情報が入っていない

## Instagram投稿前に止めるべき条件

- プロフィールリンクや受付方法が未確定
- 無料診断の対応範囲が曖昧
- 実績や数値に見える表現が混ざっている
- 医療/美容効果を断定している
- 実在店舗の画面や営業先情報が入っている
- 人間が投稿可否を判断していない
