# SNSプラットフォーム別 発信ルール

## Instagram

- 役割: 信頼形成、カルーセル、プロフィール導線
- 投稿形式: カルーセル、リール、固定投稿
- 向いている内容: 改善チェックリスト、投稿テーマ例、無料診断説明
- 避ける内容: 長文すぎる説明、成果保証
- 投稿頻度目安: 週2〜3本
- CTA: 無料SNS診断、LPリンク
- 再利用方法: Xスレッド、note記事、ショート動画へ展開

## X

- 役割: 学び、改善ログ、日々の気づき
- 投稿形式: 短文、スレッド
- 向いている内容: 営業改善ログ、SNS運用の考え方
- 避ける内容: 店舗批判、内部事情の出しすぎ
- 投稿頻度目安: 週3〜5本
- CTA: 無料診断、note/LP
- 再利用方法: Instagram投稿の下書きにする

## TikTok

- 役割: 認知獲得、短尺ノウハウ
- 投稿形式: 15〜45秒動画
- 向いている内容: SNS改善の小ネタ、プロフィール見直し
- 避ける内容: 煽り、断定、過度な効果訴求
- 投稿頻度目安: 週1〜2本
- CTA: プロフィールリンク
- 再利用方法: Reels/Shortsへ転用

## YouTube Shorts

- 役割: ショート動画の再利用、検索補助
- 投稿形式: 15〜60秒動画
- 向いている内容: チェックリスト、業態別SNSのコツ
- 避ける内容: 権利不明素材
- 投稿頻度目安: 週1〜2本
- CTA: LP/無料診断
- 再利用方法: TikTok/Reelsと同一テーマで展開

## note/blog

- 役割: 詳細解説、信頼形成
- 投稿形式: 記事
- 向いている内容: 無料診断の考え方、業態別SNS改善、月次改善
- 避ける内容: 未確認の数値実績
- 投稿頻度目安: 月1〜2本
- CTA: 無料SNS診断、LP
- 再利用方法: SNS投稿のまとめ記事にする
