# Instagram Canva素材チェックリスト 2026-06-02

## 目的

Instagram初回投稿セットをCanvaで制作する前に、必要な素材、図解、配色、権利注意を整理する。
このファイルは制作準備用であり、Canva公開、Instagram投稿、予約投稿は行わない。

## Canvaで準備する素材一覧

- ICHI Socialロゴまたは文字ロゴ
- スマホ画面風の枠
- プロフィール欄の抽象モック
- 固定投稿3枚を示すカード型図解
- 予約導線を示す矢印/線
- チェックマーク、虫眼鏡、メモ、カレンダー、吹き出しのアイコン
- 落ち着いた背景パターン
- リール用サムネイルテンプレート

## 共通デザイン方針

- 配色案: 白、淡いグレー、淡いブルー、アクセントにグリーン
- フォント方向性: 読みやすいゴシック体。見出しは太め、本文は中太。
- 写真: 初回は不要。抽象モックとアイコン中心で制作可能。
- 文字量: 1スライド1メッセージ。本文は2〜3行まで。
- 素材権利: Canva内素材でも商用利用条件を確認し、実在店舗の写真やスクリーンショットは使わない。

## アイコン案

- プロフィール: 名刺/人物アイコン
- 固定投稿: ピン/カードアイコン
- 予約導線: 矢印/カレンダーアイコン
- 診断: 虫眼鏡/チェックリストアイコン
- 改善: 工具ではなくメモや整列アイコン

## 図解案

1. プロフィール、固定投稿、予約導線を横並びにして、見る順番を矢印でつなぐ。
2. よくある悩みは4枚のカードに分け、最後に「まずは導線確認」へつなぐ。
3. 無料SNS診断はチェックリスト風にし、点検のイメージにする。
4. リールはスマホ画面内に大きなテロップを表示し、1カット1要素にする。

## 背景案

- 白地 + 淡いグレーのグリッド
- 淡いブルーのグラデーション
- ノート/チェックリスト風の薄い罫線
- 店舗らしさを邪魔しない無地背景

## NG素材例

- 実在店舗のSNS画面
- 実在店舗の写真
- 営業リスト由来の情報
- 成果を保証するグラフ
- 強い赤色の警告ばかりのデザイン
- 医療効果や美容効果を断定する素材

- 無料SNS診断の受付導線
- Canva素材の利用条件
