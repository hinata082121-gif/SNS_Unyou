# サンプル投稿・サンプル改善案ルール

## 基本ルール

- サンプルであることを明記する
- 実在店舗の情報を無断利用しない
- 実在店舗を批判しない
- 架空の数値成果を使わない
- Before/Afterは表現改善に留める
- 予約数増加などを断定しない

## 業態別に安全なサンプル例

### 美容室

- プロフィール文の整理例
- 初回来店前のFAQ
- メニュー説明の見せ方

避ける表現: 必ず似合う、集客できる、髪質が改善する保証。

### ネイル/アイラッシュ

- デザインカテゴリの整理
- 初回の流れ
- 注意事項の見せ方

避ける表現: 持ちを保証、必ず理想通り、効果断定。

### 整体

- 施術の流れ
- 相談前の不安を減らす説明
- セルフケアの一般情報

避ける表現: 治る、改善保証、医療効果の断定。

### カフェ・飲食

- メニュー紹介
- 営業日のお知らせ
- 予約/アクセス導線

避ける表現: アレルギー軽視、食品表示の不正確さ、予約数増加保証。
