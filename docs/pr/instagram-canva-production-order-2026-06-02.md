## まず作るべき投稿

最優先は **P1** と **R1**。

- P1はプロフィール固定の入口になる。
- R1は短く分かりやすく、自社アカウントの最初の動きとして出しやすい。
- どちらも成果保証や強い営業感が少なく、安全に始めやすい。

## 次点

**P2** を次に制作する。

- 小規模店舗オーナーの共感を取りやすい。
- ただし、1枚目の「損しているかも」が強く見える場合は、代替案にする。

## その次

**P3** と **R2** は、人間確認後に制作する。

- P3は受付方法、問い合わせ先、診断範囲の確定が必要。
- R2は「予約につながらない」ではなく「見つかりにくい」「迷いやすい」を使う。
