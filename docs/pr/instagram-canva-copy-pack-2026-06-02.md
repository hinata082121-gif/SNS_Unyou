# Instagram Canva貼り付け用コピー素材パック 2026-06-02

## 目的

Instagram初回投稿セットを、Canvaへ貼り付けて制作しやすい単位に分解する。
このファイルは制作素材であり、Instagram投稿、予約投稿、DM、コメントは行わない。

## 使い方

1. 投稿IDごとにCanvaテンプレートを作る。
2. 「ページ/カットごとの貼り付け文」をそのままテキストボックスへ入れる。
3. デザインメモと人間確認ポイントを確認する。
4. 書き出し後、投稿前チェックを行う。

## Hermesレビュー反映内容

- P1: 大きな修正なし。プロフィールリンクと無料診断受付方法は人間確認に残す。
- P2: 1枚目見出しを「投稿しているのに、伝わり方で損しているかも。」へ変更。代替案は「投稿しているのに、伝わり方で迷いやすいかも。」。
- P3: SNS診断を主役にし、自動化相談は補助扱いにする。「必要に応じて一緒に整理します」程度の表現へ調整。
- R1: 初回リールとして優先。15秒版はプロフィール、固定投稿、予約導線の3点に絞る。
- R2: タイトルを「予約方法が見つかりにくいSNSの確認ポイント」へ変更。サムネは「予約方法、すぐ見つかりますか？」を使う。
