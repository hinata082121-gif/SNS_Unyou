## 固定投稿3本のレビュー

### P1: このアカウントで発信すること

- 戦略整合性: 高。自社SNSの目的、対象、成果保証しない姿勢が明確。
- 品質: 初回固定投稿に適している。1枚目も分かりやすい。
- 安全性: 成果保証なしの明記あり。実在データの引用なし。
- 投稿準備度: Canva化とプロフィールリンク確認後に投稿可能。
- 推奨: 初回投稿として最優先。

### P2: 小規模店舗SNSでよくある悩み

- 戦略整合性: 高。小規模店舗の悩みに寄り添っている。
- 品質: 7枚構成で流れは自然。保存されやすいチェックリスト型。
- 安全性: 店舗批判にはなっていないが、1枚目の「伝わっていないかも」は少し強く見える可能性がある。
- 投稿準備度: 1枚目を「投稿しているのに、伝わり方で損しているかも」程度に柔らかくするとよい。
- 推奨: 軽微修正後に投稿可能。

### P3: 無料SNS診断で見るポイント

- 戦略整合性: 高。無料SNS診断への導線が自然。
- 品質: 診断範囲、約束しないこと、相談方法が整理されている。
- 安全性: 成果保証しない旨が明確。
- 投稿準備度: 実際の受付方法が確定すれば投稿可能。
- 推奨: P1、P2の後に固定投稿として出す。

## リール2本のレビュー

### R1: SNS運用、毎日投稿より先に整えるべき3つ

- フック: 強い。小規模店舗が気にしやすい「毎日投稿」を入口にしている。
- 尺: 25秒想定で現実的。15秒版へ短縮する場合は「プロフィール/固定投稿/予約導線」の3点だけに絞る。
- 安全性: 成果保証なし。実在アカウント画面を使わない前提で安全。
- 投稿準備度: テロップとスマホ風モックを作れば投稿可能候補。

### R2: Instagramから予約につながらない店舗の共通点

- フック: 実用的だが、「予約につながらない」が少し強く見える。
- 推奨修正: サムネイルや1秒目では「予約方法、すぐ見つかりますか？」のように柔らかくする。
- 尺: 30秒想定。情報量が多いため、30秒版を優先。
- 安全性: 予約数の保証はしていない。店舗批判に見えない表現調整が必要。

## キャプション・ハッシュタグのレビュー

- 基本テンプレは、成果保証を避けており安全。
- 固定投稿/リールごとのキャプション参照も整理済み。
- ハッシュタグは広すぎるタグだけに偏っておらず、店舗SNS、小規模事業者、予約導線、無料SNS診断に寄っている。
- 注意点: 業種別ハッシュタグは投稿テーマと一致する時だけ使う。初回固定投稿では基本セット中心がよい。

1. P2の1枚目を少し柔らかくする。
   - 現在: 投稿しているのに、伝わっていないかも。
   - 推奨: 投稿しているのに、伝わり方で損しているかも。
2. R2の冒頭表現を少し柔らかくする。
   - 現在: Instagramから予約につながらない店舗の共通点

3. P3は問い合わせ先、受付方法、対応範囲を人間が確認する。
4. 投稿開始日は、余裕がなければ2026-06-10開始にする。
