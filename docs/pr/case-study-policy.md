# 事例コンテンツの扱いルール

## 実績がない段階でやってよいこと

- ノウハウ投稿
- サンプル改善例
- 架空ではない自社改善ログ
- 診断で見る観点の紹介
- 業態別の一般的な改善ポイント

## 実績がない段階でやってはいけないこと

- 架空クライアント事例を実績のように見せる
- 架空数値を出す
- 「導入後に売上が増えた」など未確認の成果を書く
- 実在店舗のSNSを無断で批評する

## 架空事例を実績のように見せない

サンプルは必ず「サンプル改善例」「架空の店舗を想定した例」と明記する。

## サンプル改善例の表記方法

- サンプル改善例
- 実在店舗ではありません
- 数値成果を保証するものではありません

## クライアント許可が必要な範囲

- 店舗名
- SNS URL
- スクリーンショット
- 投稿画像
- 数値結果
- コメントや感想

## 数値実績の扱い

数値は公開許可がある場合のみ使用する。推測、平均値、架空成果は使わない。

## スクリーンショット掲載の注意

掲載許可、個人情報、第三者コメント、顔写真、予約情報が含まれていないか確認する。

## ビフォーアフター表現の注意

見た目や導線の整理に留め、売上増加や予約数増加を断定しない。

## 成果保証に見えない書き方

- 改善できる可能性
- 整理できる余地
- 伝わりやすくする
- 予約前の不安を減らす
