# 投稿前チェックリスト

- 架空実績に見えないか
- 成果保証に見えないか
- 医療/美容/飲食表現に問題がないか
- 小規模店舗向けに分かりやすいか
- CTAが自然か
- 営業色が強すぎないか
- 誤字脱字がないか
- 実在店舗を批判していないか
- スクリーンショットや素材の権利に問題がないか
- 秘密情報が含まれていないか
- クライアント名、SNS URL、数値を無断掲載していないか
- AIで作った内容を人間が確認したか

## 投稿保留にする条件

- 実績に見えるが許可がない
- 成果保証に近い
- 医療/美容/飲食の断定表現がある
- 実在店舗の批判に見える
- 認証情報や内部情報が含まれる
