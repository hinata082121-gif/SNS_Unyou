# Instagram初回投稿セット 2026-06-02

## 目的

ICHI Socialの自社Instagramを、営業前後に見られても信頼材料になる状態へ進める。初回は固定投稿3本を整え、アカウントの目的、よくある悩み、無料SNS診断への導線を自然に伝える。

## 自社Instagramアカウントの初期方針

- 対象: 小規模店舗、個人サロン、地域密着型事業者
- 優先チャネル: Instagram
- 初期投稿頻度: 週2本推奨。忙しい場合は週1本でも可
- 発信内容: プロフィール改善、予約導線、投稿テーマ、無料SNS診断、運用の考え方
- 約束すること: 伝わり方、導線、投稿テーマ、続けやすい運用を整える
- 約束しないこと: 売上、予約数、フォロワー数、検索順位、アルゴリズム表示の保証
- 投稿実行: AIは原稿制作まで。投稿、予約投稿、ログイン操作は人間が行う

## プロフィール最終案

```text
小規模店舗向けSNS運用パートナー
投稿企画・プロフィール導線・月次改善をサポート
```

- 架空実績に見えない
- 成果保証に見えない
- 実在店舗を批判していない
- 医療/美容/飲食の断定表現がない
